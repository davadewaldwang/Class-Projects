# Class Projects

Various projects from programming classes.

## csa

Projects implemented in Java. Run files from the `src` folder in `APCode3` or from `GridWorldCode`.

### APCode3/src

In each project folder, run with the runner file or the file beginning with `DewaldWang`.

### GridWorldCode

Projects that use the GridWorld framework are located in `GridWorldCode/projects/myGridWorld`. Run them with the runner file.

## ece150

Projects implemented in C++.

### Project 1

    g++ -o main project_1.cpp
    ./main
```

### Project 2

```

## Requirements

- JDK (for the `csa` projects)
- g++ (for the `ece150` projects)
